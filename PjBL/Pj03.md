## Missão 1 — Como organizar uma cidade? (100 XP)

### O problema

Uma cidade inteligente precisa organizar seus serviços (os nomes dos setores são exemplos em inglês):

```text
Central
├── Health
│   ├── Hospital
│   └── Clinic
└── Transport
    ├── Bus
    └── Subway
```

**Antes de ler a explicação, responda no papel:**

1. Qual elemento está no topo da organização?
2. Quais elementos estão diretamente ligados a `Health`?
3. Quem está acima de `Hospital`?
4. Quais elementos não possuem outros elementos abaixo deles?
5. Quantas ligações são necessárias para ir de `Central` até `Subway`?
6. Seria possível colocar `Central` como subordinada de `Hospital` sem criar uma organização circular?

### O que você descobriu

Essa organização é uma **árvore**. Seus elementos são chamados de **nós**.

| Palavra | O que significa | Exemplo |
|---|---|---|
| Raiz | Nó de onde a árvore começa | `Central` |
| Pai | Nó imediatamente acima de outro | `Health` é pai de `Hospital` |
| Filho | Nó imediatamente abaixo de outro | `Hospital` é filho de `Health` |
| Folha | Nó sem filhos | `Clinic` |
| Nível ou profundidade | Quantidade de ligações desde a raiz | `Subway` tem profundidade 2 |
| Altura de um nó | Maior número de ligações até uma folha abaixo dele | `Central` tem altura 2 |

**Regras importantes:** a raiz não tem pai; todo outro nó tem **exatamente um pai**; não existem ciclos; e, a partir da raiz, é possível chegar a todos os nós.

**Desafio:** acrescente `Education` como filha de `Central` e `School` e `Library` como filhas de `Education`. Agora determine quantos nós, folhas e níveis existem.

**Dica:** conte os próprios nomes para descobrir os nós; para as folhas, procure quem não tem filhos. Aqui, a raiz está no nível 0.

**Antes de avançar:** por que uma árvore representa bem departamentos de uma organização, mas não necessariamente todas as ruas de uma cidade?

## Missão 2 — Transforme o desenho em código (100 XP)

### O problema

Queremos representar `Central`, `Health`, `Hospital` e os demais elementos em Java. Você já conhece `List`. Como guardar um elemento e seus filhos?

**Pense primeiro:**

- Uma `List<String>` guarda os nomes, mas consegue indicar **quem é filho de quem**?
- E se cada elemento guardasse **seu próprio nome e uma lista de outros elementos**?
- Um filho poderia guardar outra lista de filhos?

### Passo 1 — Crie `CityTree.java`

```java
import java.util.*;

public class CityTree {
    static class Node {
        final String name;
        final List<Node> children = new ArrayList<>();

        Node(String name) {
            this.name = name;
        }

        Node addChild(String name) {
            Node newChild = new Node(name);
            children.add(newChild);
            return newChild;
        }
    }

    static Node buildTree() {
        Node central = new Node("Central");

        Node health = central.addChild("Health");
        health.addChild("Hospital");
        health.addChild("Clinic");

        Node transport = central.addChild("Transport");
        transport.addChild("Bus");
        transport.addChild("Subway");

        return central;
    }

    public static void main(String[] args) {
        Node root = buildTree();
        System.out.println(root.name);
        System.out.println(root.children.size());
    }
}
```

Execute `CityTree` pela sua IDE (por exemplo, IntelliJ IDEA ou VS Code).

Saída esperada:

```text
Central
2
```

### Entenda o que aconteceu

- `Node` representa **um elemento**.
- `List<Node>` representa seus **filhos**.
- O método `addChild` cria um filho e devolve esse filho para que você possa acrescentar os descendentes dele.
- `buildTree()` devolve a raiz de toda a organização.

**Desafio:** modifique `buildTree()` para acrescentar `Education`, `School` e `Library`, como na missão anterior.

**Teste:** `root.children.size()` deve passar de `2` para `3`.

**Pergunta:** por que `List<Node>` permite formar vários níveis, sem precisar criar uma classe para cada nível?

> A partir de agora, acrescente os novos métodos **dentro de `CityTree`**, mas **fora do método `main`**. Para os primeiros testes, mantenha a árvore original, com sete nós.

## Missão 3 — Visite todos os setores usando uma fila (100 XP)

### O problema

Um coordenador quer consultar os setores **nível por nível**: primeiro a Central, depois seus setores e, por último, os serviços de cada setor.

**Sem programar:** escreva a ordem em que os sete nós devem aparecer.

**Pergunta decisiva:** entre lista, pilha e fila, qual estrutura atende primeiro os elementos que chegaram primeiro?

### A estratégia

1. Coloque a raiz na **fila**.
2. Retire o primeiro nó.
3. Visite esse nó.
4. Coloque seus filhos no fim da fila.
5. Repita até não haver ninguém na fila.

Isso se chama **percurso em largura**, ou **percurso por níveis**.

### Programe

Adicione o método à classe `CityTree`:

```java
static List<String> breadthFirst(Node root) {
    List<String> order = new ArrayList<>();
    Queue<Node> queue = new ArrayDeque<>();

    queue.add(root);

    while (!queue.isEmpty()) {
        Node current = queue.remove();
        order.add(current.name);

        for (Node child : current.children) {
            queue.add(child);
        }
    }

    return order;
}
```

No `main`, teste:

```java
System.out.println(breadthFirst(root));
```

Resultado esperado para a árvore original:

```text
[Central, Health, Transport, Hospital, Clinic, Bus, Subway]
```

**Investigue:** acompanhe a fila após visitar `Central` e depois após visitar `Health`. Quais elementos estão esperando em cada momento?

**Desafio:** crie `contains(Node root, String name)`, que devolva `true` quando encontrar um setor e `false` quando ele não existir.

**Dicas graduais:**

1. Reaproveite a fila do método `breadthFirst`.
2. Compare `current.name.equals(name)` após retirar cada nó.
3. Se encontrar, retorne `true` imediatamente. Se a fila acabar, retorne `false`.

**Testes:** `contains(root, "Hospital")` deve ser `true`; `contains(root, "Airport")` deve ser `false`.

## Missão 4 — Explore um setor por inteiro usando uma pilha (100 XP)

### O problema

Outra equipe precisa concluir **todos os serviços do setor `Health` antes de começar `Transport`**. Percorrer por níveis não atende a essa necessidade.

**Pergunta:** como visitar um setor, depois um de seus filhos, e continuar descendo antes de voltar aos irmãos?

Você já conhece uma estrutura em que o **último a entrar é o primeiro a sair**: a **pilha**.

### Programe

```java
static List<String> depthFirst(Node root) {
    List<String> order = new ArrayList<>();
    Deque<Node> stack = new ArrayDeque<>();

    stack.push(root);

    while (!stack.isEmpty()) {
        Node current = stack.pop();
        order.add(current.name);

        // Push children in reverse order to visit
        // them in their original order.
        for (int i = current.children.size() - 1; i >= 0; i--) {
            stack.push(current.children.get(i));
        }
    }

    return order;
}
```

No `main`:

```java
System.out.println(depthFirst(root));
```

Resultado esperado:

```text
[Central, Health, Hospital, Clinic, Transport, Bus, Subway]
```

Isso é um **percurso em profundidade**. Como visitamos cada nó **antes** dos seus filhos, essa ordem é chamada de **pré-ordem**.

**Desafio:** troque o laço `for` por um laço que empilhe os filhos do primeiro ao último. Preveja como a saída mudará e depois execute.

**Pergunta:** qual percurso escolheria para ver setores por nível? E qual escolheria para terminar um departamento inteiro antes do próximo?

## Missão 5 — Descubra a recursão e analise a árvore (100 XP)

### O problema

A prefeitura precisa saber:

- Quantos nós existem na organização?
- Quantos nós são **folhas**?
- Qual é a **altura** da organização?

Até agora, usamos fila e pilha. Mas há outra possibilidade: **pedir que cada filho resolva uma parte menor do problema**.

### Passo 1 — Conte os nós

Imagine o seguinte raciocínio:

> A quantidade de nós de um setor é **1 (o próprio setor) + a quantidade de nós de todos os seus filhos**.

Esse raciocínio pode ser escrito assim:

```java
static int countNodes(Node node) {
    int total = 1;

    for (Node child : node.children) {
        total += countNodes(child);
    }

    return total;
}
```

Esse método chama **ele mesmo** para resolver problemas menores. Isso é **recursão**.

A recursão termina porque, ao alcançar uma folha, `node.children` está vazio: o `for` não executa e o método devolve `1`.

Teste em `main`:

```java
System.out.println(countNodes(root)); // 7
```

### Passo 2 — Sua vez: conte as folhas

Crie este método e preencha as partes indicadas:

```java
static int countLeaves(Node node) {
    // TODO: if node.children is empty, return 1.

    int total = 0;
    for (Node child : node.children) {
        // TODO: add the number of leaves for each child.
    }
    return total;
}
```

**Dicas:**

1. Use `node.children.isEmpty()` para identificar uma folha.
2. A contagem de folhas **não** inclui o próprio nó quando ele tem filhos.
3. A chamada recursiva tem a forma `countLeaves(child)`.

**Resultado esperado:** `4`.

### Passo 3 — Desafio: calcule a altura

Neste tutorial, medimos a altura em **ligações**. Assim, uma folha tem altura `0`.

**Raciocínio:**

- Se um nó não possui filhos, sua altura é `0`.
- Se possui filhos, sua altura é **1 + a maior altura entre seus filhos**.

Implemente `static int height(Node node)` usando `Math.max` e recursão.

**Resultado esperado:** `2`.

**Perguntas finais:** qual é a condição que faz cada chamada recursiva parar? O que aconteceria se os nós formassem um ciclo?

## Missão 6 — Encontre códigos sem examinar tudo (100 XP)

### O problema

Agora a cidade precisa organizar números de chamados. Uma lista pode armazená-los, mas como encontrá-los sem verificar cada elemento?

Considere estes números, inseridos nesta ordem:

```text
40, 20, 60, 10, 30, 50, 70
```

Desenhe uma estrutura seguindo duas regras:

1. Cada nó tem **no máximo dois filhos**: esquerda e direita.
2. Números **menores** ficam na subárvore da esquerda; números **maiores**, na da direita.

O desenho correto fica assim:

```text
        40
       /  \
     20    60
    /  \  /  \
   10  30 50  70
```

Essa estrutura é uma **árvore binária de busca (ABB)**. Observe que agora cada nó precisa de apenas duas referências: `left` e `right`.

**Antes de programar:**

1. Para procurar `30`, qual comparação você faz primeiro?
2. Depois de encontrar `20`, para qual lado deve seguir?
3. Se procurar `99`, em que momento saberá que o número não existe?

### Passo 1 — Crie `BinarySearchTree.java`

```java
public class BinarySearchTree {
    static class Node {
        final int value;
        Node left;
        Node right;

        Node(int value) {
            this.value = value;
        }
    }

    static Node insert(Node node, int value) {
        if (node == null) return new Node(value);

        if (value < node.value) {
            node.left = insert(node.left, value);
        } else if (value > node.value) {
            node.right = insert(node.right, value);
        }

        // Duplicate values are ignored.
        return node;
    }

        return false;
    }

    public static void main(String[] args) {
        Node root = null;
        int[] numbers = {40, 20, 60, 10, 30, 50, 70};

        for (int number : numbers) {
            root = insert(root, number);
        }

        System.out.println(contains(root, 30));
        System.out.println(contains(root, 99));

```

> No início, o método `contains` sempre devolve `false`: isso é **intencional**. Sua tarefa é completá-lo.

### Passo 2 — Implemente a busca

Use estas decisões, nesta ordem:

1. Se o nó recebido é `null`, o número não foi encontrado.
2. Se `node.value == value`, encontramos o número.
3. Se `value < node.value`, procure na esquerda.
4. Caso contrário, procure na direita.

**Dica:** chamadas como `contains(node.left, value)` resolvem a busca em uma parte menor da árvore.

## Missão 7 — Mostre os códigos em ordem e descubra uma limitação (100 XP)

### O problema

O gestor quer imprimir todos os números em **ordem crescente**, sem copiá-los para uma lista e usar `sort`.

**Investigue o desenho da missão anterior:**

- Onde estão os menores números?
- Onde está o número intermediário de cada parte da árvore?
- Onde estão os maiores?

A ordem que resolve o problema é: **esquerda → nó atual → direita**. Ela é chamada de **percurso em ordem**.

### Programe

Acrescente a `BinarySearchTree`:

```java
static void inOrder(Node node) {
    if (node == null) return;

    inOrder(node.left);
    System.out.print(node.value + " ");
    inOrder(node.right);
}
```

Chame ao final do `main`:

```java
inOrder(root);
System.out.println();
```

Resultado esperado, antes de inserir `25` e `65`:

```text
10 20 30 40 50 60 70
```

### Um problema inesperado

Crie outra árvore e insira, nesta ordem:

```text
10, 20, 30, 40, 50
```

**Desenhe o resultado.** Ela fica parecida com uma lista inclinada para a direita. A busca pode precisar percorrer quase todos os nós.

**O que você aprendeu:** a busca em uma ABB depende da **altura** da árvore.

- Em uma árvore bem distribuída, a busca tende a ser eficiente: **O(log n)**.
- Em uma árvore muito inclinada, pode chegar a **O(n)**.

> Uma ABB simples não se equilibra automaticamente. Mais adiante, você poderá estudar árvores AVL e rubro-negras para resolver esse problema.

**Desafio para concluir a missão:** explique, usando os dois desenhos, por que a mesma regra de inserção pode produzir árvores com alturas diferentes.

## Resumo para consultar enquanto programa

| Necessidade | Técnica | Estrutura usada |
|---|---|---|
| Organizar informações hierárquicas | Árvore geral | Nó + `List<Node>` |
| Percorrer nível por nível | Busca em largura | `Queue` / `ArrayDeque` |
| Explorar um ramo antes dos outros | Busca em profundidade | `Deque` como pilha |
| Contar nós ou calcular altura | Recursão | Chamadas de métodos |
| Pesquisar valores ordenados | Árvore binária de busca | Nó com `left` e `right` |
| Imprimir ABB em ordem crescente | Percurso em ordem | Recursão |

### Missão 5 — Contar folhas e calcular altura

Adicione dentro de `CityTree`:

```java
static int countLeaves(Node node) {
    if (node.children.isEmpty()) return 1;

    int total = 0;
    for (Node child : node.children) {
        total += countLeaves(child);
    }
    return total;
}

static int height(Node node) {
    int maxHeight = 0;
    for (Node child : node.children) {
        maxHeight = Math.max(maxHeight, 1 + height(child));
    }
    return maxHeight;
}
```

### Missão 6 — Pesquisar na ABB

Substitua o método `contains` de `BinarySearchTree` por:

```java
static boolean contains(Node node, int value) {
    if (node == null) return false;
    if (node.value == value) return true;

    if (value < node.value) {
        return contains(node.left, value);
    }
    return contains(node.right, value);
}
```

### Missão 7 — Por que a altura importa?

Inserindo `40, 20, 60, 10, 30, 50, 70`, a árvore tem altura **2**. Inserindo `10, 20, 30, 40, 50`, todos os nós ficam à direita do anterior e a altura fica **4**. Por isso, nem toda ABB oferece a mesma eficiência de busca.
