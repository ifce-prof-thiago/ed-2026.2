# 2. Laboratório preparatório: você conhece listas, filas e pilhas. E um mapa?

Antes do problema principal, recorde três estruturas conhecidas:

- **Lista:** guarda elementos em sequência. Exemplo: pessoas esperando atendimento por ordem de cadastro.
- **Fila:** quem entra primeiro sai primeiro (FIFO). Exemplo: atendimento por chegada.
- **Pilha:** quem entra por último sai primeiro (LIFO). Exemplo: desfazer ações.

Agora imagine um aplicativo que recebe o nome de um bairro e precisa devolver todos os bairros conectados diretamente a ele. Uma lista de nomes seria suficiente para organizar essa consulta de forma prática?

## 2.1. Descobrindo um dicionário (`Map`)

Um `Map` associa uma **chave** a um **valor**. Neste exemplo, o valor será uma lista de nomes:

```java
import java.util.List;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        Map<String, List<String>> contatos = Map.of(
                "Hospital", List.of("Escola", "Ponte"),
                "Escola", List.of("Hospital", "Abrigo"),
                "Ponte", List.of("Hospital", "Abrigo"),
                "Abrigo", List.of("Escola", "Ponte")
        );

        System.out.println(contatos.get("Hospital"));
        System.out.println(contatos.get("Abrigo"));
    }
}
```

**Experimente antes de prosseguir:**

1. Consulte uma chave inexistente. Qual resultado aparece?
2. Por que `Map.of(...)` é bom para exemplos fixos, mas inadequado para ir adicionando bairros em tempo de execução?
3. Que tipo de dado o programa deverá guardar se cada cidade puder ter dezenas de conexões?

O `Map.of` cria um mapa que não permite adicionar/remover entradas. Para editar, usaremos `LinkedHashMap` (mantém uma ordem previsível de iteração):

```java
Map<String, List<String>> contatos = new java.util.LinkedHashMap<>();
contatos.put("Hospital", new java.util.ArrayList<>());
contatos.get("Hospital").add("Escola");
```

Mais à frente utilizaremos um `Set`, coleção que não admite elementos duplicados. Não é necessário conhecê-lo agora; você descobrirá por que ele é valioso quando aparecer o risco de visitar o mesmo lugar repetidamente.

> **Checkpoint:** explique com suas palavras a diferença entre `List<String>` e `Map<String, List<String>>`.

# MISSÃO 1 — O MUNDO DAS CONEXÕES

**Recompensa:** 50 XP · **Duração sugerida:** 1 aula · **Papel da equipe:** cartógrafos digitais.

## O problema

A cidade tem cinco locais: **Hospital, Escola, Ponte, Abrigo e Central**. Existem ligações entre eles:

```text
Hospital —— Escola
   |           |
 Ponte ————— Abrigo —— Central
```

Neste desenho, Hospital está ligado a Escola e Ponte; Escola está ligada a Abrigo; Ponte está ligada a Abrigo; Abrigo está ligado a Central. Cada linha representa uma ligação possível nos **dois sentidos**.

O conselho quer saber:

1. Quais lugares são vizinhos diretos do Hospital?
2. É possível ir do Hospital à Central?
3. Quantas ligações existem?
4. Há mais de um jeito de chegar ao Abrigo?
5. E se a Ponte for interditada: ainda existe um caminho até o Abrigo?

## Desafio 1A — Descubra uma representação

**Sem programar**, crie uma tabela de duas colunas: local e seus vizinhos. Depois desenhe o mapa como círculos (locais) unidos por linhas (conexões).

**Investigue:** a ordem em que os locais aparecem no desenho altera as ligações? Uma ligação entre A e B precisa aparecer também entre B e A? Isso dependerá do tipo de problema?

## Desafio 1B — Programe da maneira que você já conhece

Comece com a estrutura `Map<String, List<String>>` do laboratório. Cadastre os cinco lugares e suas ligações. O primeiro resultado desejado é:

```text
Vizinhos de Hospital: [Escola, Ponte]
Vizinhos de Central: [Abrigo]
```

**Não crie ainda uma classe `Grafo`.** Use somente as ferramentas conhecidas. Se funcionar, explique por que escolheu a representação.

## O que você acabou de descobrir

A estrutura matemática formada por **elementos** e suas **relações** recebe o nome de **grafo**.

- Cada local é um **vértice** (ou nó).
- Cada ligação é uma **aresta**.
- Os locais conectados diretamente são **vizinhos** ou **adjacentes**.
- Uma sequência de vértices conectados é um **caminho**.
- O número de ligações incidentes em um vértice de grafo não direcionado é seu **grau** (uma ligação do vértice a ele próprio, chamada laço, conta duas vezes no grau matemático).
- Quando a ligação funciona nos dois sentidos, o grafo é **não direcionado**. Quando funciona em apenas um, é **direcionado**.

**Descoberta importante:** um grafo não precisa representar lugares. Em outras aplicações, vértices podem ser pessoas, disciplinas, páginas da web, componentes eletrônicos ou tarefas.

## O problema

## Desafio 2A — Desenhe a interface antes da implementação

Imagine que o restante do programa consiga escrever:

```java
Grafo cidade = new Grafo(false); // false: ruas nos dois sentidos
cidade.adicionarVertice("Hospital");
cidade.adicionarVertice("Escola");
cidade.conectar("Hospital", "Escola", 4);
System.out.println(cidade.vertices());
System.out.println(cidade.vizinhos("Hospital"));
```

**Por que `4` aparece na conexão?** Ainda não vamos utilizá-lo. Imagine que esse número possa indicar quilômetros, minutos ou custo de instalação. Guardá-lo agora prepara a cidade para os próximos desafios.

## Desafio 2B — Crie `Grafo.java` em etapas

**Etapa 1 — estrutura mínima:**

```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public final class Grafo {
    private final Map<String, List<String>> vizinhanca = new LinkedHashMap<>();

    public void adicionarVertice(String nome) {
        vizinhanca.putIfAbsent(nome, new ArrayList<>());
    }

    public List<String> vizinhos(String nome) {
        return List.copyOf(vizinhanca.get(nome));
    }
}
```

Experimente o código e encontre o problema: o que ocorre quando `nome` não existe? Uma exceção sem contexto é uma boa experiência para quem usa seu código?

**Etapa 2 — conexões:** implemente um método `conectar(String origem, String destino)` que:

1. Garanta a existência dos dois lugares.
2. Adicione `destino` à lista de `origem`.
3. Se a cidade possui ruas de mão dupla, adicione também `origem` à lista de `destino`.
4. Não repita uma conexão já cadastrada.

**Etapa 3 — direção:** adicione um campo `boolean direcionado` recebido no construtor. Agora `new Grafo(true)` representa conexões de mão única.

**Etapa 4 — pesos:** substitua `List<String>` por `List<Aresta>`, em que cada aresta guarda destino e custo:

```java
public record Aresta(String destino, int custo) {}
```

A declaração pode ficar **dentro da classe** `Grafo`. Um `record` é uma maneira concisa de criar um tipo de dado com componentes e métodos de acesso, como `destino()` e `custo()`.

A estrutura interna passará a ser:

```java
private final Map<String, List<Aresta>> adjacencias = new LinkedHashMap<>();
```

> **Não copie a solução final de imediato.** Transforme seu código etapa por etapa. A mudança de `String` para `Aresta` vai provocar erros de compilação; corrija cada ocorrência conscientemente.

## Desafio 2C — Provoque falhas

- Tente criar uma conexão duplicada. Qual comportamento decidiu adotar: ignorar, substituir ou lançar erro? Documente sua escolha.
- Tente usar um custo negativo. Esse tipo de dado fará sentido em uma rota de quilômetros? Explique.
- Insira um bairro totalmente isolado. Ele continua sendo um vértice?
- Tente modificar a lista recebida por `vizinhos()`. Seu código permite alterar o grafo sem passar pelos métodos oficiais? Por que isso é perigoso?

## Descoberta conceitual

Você construiu uma **lista de adjacência**, uma das maneiras mais comuns de armazenar grafos. Para cada vértice, o sistema guarda sua lista de arestas de saída.

Outra alternativa é a **matriz de adjacência**, uma tabela `V × V` em que uma posição informa se existe uma conexão. Ela será útil quando a consulta direta de existência de aresta for frequente, mas pode desperdiçar memória em redes com poucas conexões.

| Representação | Memória típica | Boa quando... |
|---|---|---|
| Lista de adjacência | `O(V + E)` | A maioria dos pares não está conectada |
| Matriz de adjacência | `O(V²)` | O grafo é denso ou se consulta a existência de arestas com frequência |

Aqui, `V` é o número de vértices e `E` o número de arestas. Para simplificar a análise, consideramos operações de acesso a `Map` com custo médio próximo de constante; essa hipótese depende da implementação.

<details><summary>Pista 2</summary>Use `computeIfAbsent(nome, chave -> new ArrayList<>())` para criar listas sob demanda.</details>
<details><summary>Pista 3</summary>Use `List.copyOf(...)` ao devolver os vizinhos para impedir alterações externas. Veja a implementação de referência no apêndice se já esgotou as tentativas.</details>

# MISSÃO 3 — ENCONTRE OS SOBREVIVENTES

**Recompensa:** 100 XP · **Duração sugerida:** 2 aulas · **Papel:** coordenadores de resgate.

## O problema

Após a tempestade, uma equipe parte do Hospital para localizar pessoas que precisam de atendimento. Para organizar a busca, os resgatistas querem visitar primeiro os locais que estão a **uma conexão** do Hospital, depois os que estão a **duas conexões**, e assim sucessivamente.

Mapa de investigação:

```text
Hospital —— Escola —— Abrigo —— Central
   |                    |
 Ponte ——————————————————┘

Bairro Isolado (sem ligação)
```

Cadastre as ligações nesta ordem: Hospital–Escola, Hospital–Ponte, Escola–Abrigo, Ponte–Abrigo, Abrigo–Central. Os custos podem ser `1` por enquanto.

## Desafio 3A — Resolva sem código

Use cartões com nomes dos lugares. Você só pode examinar os vizinhos de **um lugar por vez**. Para garantir que os mais próximos sejam examinados primeiro, qual estrutura você usaria: lista, fila ou pilha? Por quê?

Preencha a tabela manual:

| Passo | Lugar retirado | Fila depois de descobrir novos lugares | Já descobertos |
|---|---|---|---|
| 0 | — | `[Hospital]` | Hospital |
| 1 | Hospital | `[...]` | ... |
| 2 | ... | `[...]` | ... |
| 3 | ... | `[...]` | ... |

**Atenção:** se um lugar aparecer como vizinho de dois outros lugares, ele não deve entrar na fila duas vezes. Caso contrário, surgirá trabalho desnecessário — ou loops em variantes ingênuas.

## Desafio 3B — Descubra o papel do `Set`

```java
import java.util.HashSet;
import java.util.Set;

Set<String> descobertos = new HashSet<>();
System.out.println(descobertos.add("Hospital")); // true
System.out.println(descobertos.add("Hospital")); // false
```

O `Set` informa se aquele elemento é novo. A chamada `add` combina duas operações: tentar registrar um lugar e descobrir se ele já havia sido registrado.

**Investigue:** em que momento registrar um lugar como descoberto: quando entra na fila ou quando sai dela? Que consequência isso tem para repetições?

## Desafio 3C — Complete o algoritmo

Crie `Algoritmos.java`:

```java
        fila.add(inicio);
        descobertos.add(inicio);

            String atual = fila.remove();
            ordem.add(atual);

            // TODO: percorra grafo.vizinhos(atual).
            // TODO: descubra os novos lugares.
            // TODO: enfileire somente os lugares novos.
        }
        return ordem;
    }
}
```

Seu código precisa extrair o destino de cada objeto `Grafo.Aresta` por meio de `aresta.destino()`.

Se usar exatamente a ordem de cadastro proposta e uma lista de adjacência que preserve a ordem, o resultado esperado será:

```text
[Hospital, Escola, Ponte, Abrigo, Central]
```

O Bairro Isolado não deve aparecer: não existe uma sequência de conexões desde o Hospital até ele.

## Desafio 3D — Encontre o caminho com menos passos

O Conselho agora precisa da **sequência de lugares** de Hospital até Central, escolhendo a rota com o menor número de **arestas**, não de quilômetros.

**Questões orientadoras:**

1. Quando um vértice é descoberto pela primeira vez em uma busca em largura, ele chegou por um caminho com quantos passos em relação aos demais candidatos ainda não descobertos?
2. Se você guardar para cada local **quem o descobriu**, conseguiria remontar a rota do final até o início?
3. Que estrutura representa bem a associação `destino → predecessor`?

Use:

```java
Map<String, String> anterior = new HashMap<>();
```

Na descoberta de um novo vértice `proximo` a partir de `atual`, registre `anterior.put(proximo, atual)`. Depois reconstrua o caminho de trás para frente.

**Saída esperada:** caminho de **três conexões** entre Hospital e Central. Há duas rotas mínimas possíveis: via Escola ou via Ponte, dependendo da ordem em que os vizinhos forem examinados.

## O nome do que você descobriu

A abordagem chama-se **Busca em Largura** (*Breadth-First Search*, BFS). Ela explora o grafo em camadas de distância medidas em **quantidade de arestas**. Seu custo típico com listas de adjacência é `O(V + E)`.

**Muito importante:** BFS **não** garante o menor custo quando ruas possuem pesos diferentes. Essa dificuldade motivará a missão 5.

## Pistas graduais

<details><summary>Pista 2</summary>`if (descobertos.add(proximo)) { fila.add(proximo); }` insere apenas locais novos.</details>
<details><summary>Pista 3</summary>Para recuperar um caminho, siga `anterior.get(destino)` repetidamente até encontrar o início e inverta a ordem dos elementos.</details>

## Desafio 7C — Programe a liberação de tarefas

Crie `ordenacaoTopologica(Grafo grafo)`:

```java
public static List<String> ordenacaoTopologica(Grafo grafo)
```

1. Construa um `Map<String, Integer>` com o grau de entrada de cada tarefa.
2. Coloque em uma fila todas as tarefas com grau zero.

**Importante:** não existe ordenação topológica de um grafo dirigido que contenha um ciclo. O problema não é o programa; o planejamento precisa ser corrigido.

## O problema

A cidade precisa instalar cabos entre pontos estratégicos. Cada possível conexão possui um custo de instalação. Não é necessário construir todas as conexões disponíveis: basta que todos os locais consigam se comunicar, diretamente ou por intermédio de outros locais.

Considere esta rede de **possibilidades**, todas de mão dupla:

| Conexão possível | Custo |
|---|---:|
| A — B | 2 |
| A — C | 3 |
| B — C | 1 |
| B — D | 4 |
| C — D | 5 |

**Desafio:** escolha um conjunto de conexões que una os quatro lugares usando o **menor custo total**.

## Desafio 8A — Experimente no papel

Comece selecionando as arestas mais baratas:

1. B—C, custo 1.
2. A—B, custo 2.
3. A—C, custo 3. **Ela é realmente necessária?**
4. B—D, custo 4.

Se A já chega a C passando por B, construir A—C só acrescentaria custo. Isso sugere uma regra: **evite adicionar uma aresta que feche um ciclo** quando o objetivo é somente conectar os lugares.

A solução ótima deste exemplo possui custo **7**: B—C (1), A—B (2), B—D (4).

## Desafio 8B — Descubra a estrutura da solução

Uma rede que conecta todos os `V` vértices **sem ciclos** é uma **árvore geradora**. Se o custo total é mínimo entre todas as árvores geradoras, temos uma **árvore geradora mínima** (*Minimum Spanning Tree*, MST).

**Perguntas:**

1. Quantas arestas possui uma árvore com `V` vértices?
2. Por que adicionar uma aresta que já conecta dois locais do mesmo grupo cria um ciclo?
3. Como descobrir rapidamente se dois locais já pertencem ao mesmo grupo de conexões selecionadas?

## Desafio 8C — Crie um controle de grupos

Uma alternativa simples seria usar BFS para conferir se cada nova aresta fecha um ciclo. Ela funciona, mas pode desperdiçar tempo ao repetir buscas.

Conheça uma estrutura auxiliar chamada **União–Busca** (*Union-Find* ou *Disjoint Set Union*, DSU). Ela mantém grupos e oferece duas operações:

- `encontrar(x)`: identifica o representante do grupo de `x`.
- `unir(a, b)`: une os grupos somente se forem diferentes; informa se houve união.

**Experimento sem código:** inicialmente, `{A}`, `{B}`, `{C}`, `{D}`. Ao escolher B—C, surgem `{A}`, `{B,C}`, `{D}`. Ao escolher A—B, surgem `{A,B,C}`, `{D}`. A—C seria redundante. B—D conecta os grupos restantes.

## Desafio 8D — Programe o algoritmo

Crie `kruskal(Grafo grafo)`.

**Estratégia orientadora:**

1. Reúna todas as arestas **uma única vez** (em grafo não direcionado, uma conexão pode estar nas duas listas de adjacência).
2. Ordene-as por custo crescente.
3. Inicialize os grupos com cada vértice separado.
4. Para cada aresta, una os grupos se ainda forem distintos. Apenas nesse caso, aceite a aresta e some seu custo.
5. Ao final, verifique se todos os vértices foram conectados.

Utilize, se desejar, estes tipos:

```java
public record Conexao(String origem, String destino, int custo) {}

public record ResultadoRede(
        List<Conexao> conexoes,
        long custoTotal,
        boolean conectaTudo) {}
```

## O que você descobriu

A estratégia é o **algoritmo de Kruskal**. O custo principal vem de ordenar as arestas: aproximadamente `O(E log E)`, combinado às operações de União–Busca, que são muito eficientes com compressão de caminhos e união por tamanho ou posto.

**Atenção a uma condição importante:** se o grafo original não for conexo, não existe árvore geradora capaz de unir todos os vértices usando apenas as arestas disponíveis. Nesse caso, o algoritmo encontra uma **floresta geradora mínima**, isto é, uma árvore mínima para cada componente.

# MISSÃO 9 — A ROTA ORIENTADA POR ESTIMATIVAS

O sistema de emergências já consegue calcular rotas de menor custo usando Dijkstra. Mas a cidade possui muitos locais. Será possível usar uma **estimativa do que falta até o destino** para tornar a busca mais orientada?

Uma estimativa poderia ser a distância em linha reta entre a localização atual e a Central.

## Desafio 9A — A diferença entre custo conhecido e estimativa

Considere:

- `g(n)`: custo real acumulado do início até o local `n`.
- `h(n)`: estimativa do custo que ainda falta de `n` até o destino.
- `f(n) = g(n) + h(n)`: valor usado para decidir qual local parece mais promissor.

**Discussão:** Dijkstra prioriza somente `g(n)`. O que acontece se priorizarmos `g(n) + h(n)`?

**Hipótese para testar:** uma boa estimativa pode reduzir o trabalho da busca, mas uma estimativa incorreta pode comprometer a garantia de rota ótima.

## Desafio 9B — Registre coordenadas

Adicione uma tabela de pontos em um plano cartesiano:

| Lugar | x | y |
|---|---:|---:|
| A | 0 | 0 |
| B | 2 | 0 |
| C | 0 | 3 |
| D | 3 | 3 |
| E | 6 | 3 |

Use um `record`:

```java
public record Ponto(double x, double y) {}
```

A distância euclidiana entre dois pontos pode ser calculada em Java por:

```java
double distancia = Math.hypot(a.x() - b.x(), a.y() - b.y());
```

**Condição do experimento:** o custo de cada aresta deve ser **pelo menos** a distância em linha reta entre suas extremidades. Assim, `h(n)` não superestima o menor custo restante, desde que todas as arestas tenham custos não negativos e se usem as mesmas unidades. Essa é uma condição suficiente para a heurística euclidiana usada aqui ser consistente.

## Desafio 9C — Construa e teste

```text
C—D: 3    D—E: 3    B—E: 9
```

## Conceito revelado

Se o custo representar **tempo** e não distância, uma estimativa geométrica em quilômetros precisa ser convertida para uma cota inferior de tempo por meio de uma velocidade máxima válida; caso contrário, misturar unidades pode invalidar as garantias.

## Como ler `O(V + E)` e outras expressões

Uma medida de complexidade descreve **como o trabalho cresce** quando a entrada cresce. Não é uma promessa de tempo exato em segundos.

- `V` (*vertices*): número de lugares.
- `E` (*edges*): número de conexões; em grafo não direcionado, cada ligação é uma aresta, embora possa aparecer duas vezes na lista de adjacência.
- `O(V + E)`: uma busca que examina vértices e arestas em quantidade proporcional à entrada.
- `O(E log E)`: típico da ordenação de arestas no Kruskal.
- `O((V + E) log V)`: uma forma usual de expressar o Dijkstra com heap em grafos simples. Em implementações que inserem estados duplicados na fila, o limite pode ser expresso de forma mais geral como `O((V + E) log(V + E))`; ambos coincidem assintoticamente em grafos simples de tamanho usual.

**Exercício:** compare dois grafos com 20 vértices: um com 19 arestas e outro com 150. Por que uma matriz pode ser menos desperdiçadora no segundo caso, embora a lista de adjacência continue válida?

# 6. GUIA DE BOAS PRÁTICAS DE JAVA

Os exemplos foram elaborados para Java 21+ e adotam recursos simples e atuais, sem exigir conhecimento de frameworks.

## 6.1. Use `record` para dados

```java
record Aresta(String destino, int custo) {}
record Rota(List<String> caminho, long custo) {}
```

`record` gera construtor, métodos de acesso, `equals`, `hashCode` e `toString` adequados aos componentes declarados. Se um componente for uma lista, o `record` não a torna profundamente imutável por si só. Você pode criar uma cópia defensiva no construtor compacto:

```java
record Rota(List<String> caminho, long custo) {
    public Rota {
        caminho = List.copyOf(caminho);
    }
}
```

## 6.2. Prefira interfaces na declaração

```java
List<String> ordem = new ArrayList<>();
Queue<String> fila = new ArrayDeque<>();
Deque<String> pilha = new ArrayDeque<>();
Map<String, Integer> distancias = new HashMap<>();
Set<String> visitados = new HashSet<>();
```

Assim, o código depende da capacidade da coleção, não de detalhes desnecessários da implementação.

## 6.3. Não ignore erros silenciosamente

```java
if (!grafo.contemVertice(inicio)) {
    throw new IllegalArgumentException("Local inexistente: " + inicio);
}
```

Defina um comportamento explícito para origem/destino inválidos, caminhos inexistentes, custos negativos e grafo desconectado.

## 6.4. Faça testes pequenos sem bibliotecas externas

```java
static void verificar(boolean condicao, String mensagem) {
    if (!condicao) {
        throw new AssertionError("Falha: " + mensagem);
    }
    System.out.println("[OK] " + mensagem);
}
```

Você pode escrever verificações no `Main` e executá-las pelo terminal. Mais tarde, migre esses testes para JUnit se a disciplina já utilizar uma ferramenta de testes automatizados.

## 6.5. Entenda as escolhas de implementação

- `LinkedHashMap` mantém ordem de iteração previsível, útil para exemplos reproduzíveis.
- `HashSet` permite consultar presença em tempo médio próximo de constante, mas não garante ordem de iteração.
- `List.copyOf` protege a coleção retornada contra alterações externas diretas.
- `PriorityQueue` é uma fila ordenada por prioridade; **não** significa que iterar sobre ela produzirá todos os elementos em ordem de prioridade.
- `ArrayDeque` pode servir de fila (`add`/`remove`) ou pilha (`push`/`pop`).
- No Dijkstra, entradas antigas na fila de prioridade podem ser ignoradas quando uma distância melhor já foi descoberta.

## Arquivo `Grafo.java`

```java
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Objects;
import java.util.Set;

/** Grafo com pesos inteiros não negativos e nomes únicos para os vértices. */
public final class Grafo {
    public record Aresta(String destino, int custo) {}

    private final boolean direcionado;
    private final Map<String, List<Aresta>> adjacencias = new LinkedHashMap<>();

    public Grafo(boolean direcionado) {
        this.direcionado = direcionado;
    }

    public boolean direcionado() {
        return direcionado;
    }

    public void adicionarVertice(String nome) {
        Objects.requireNonNull(nome, "O nome não pode ser nulo");
        if (nome.isBlank()) {
            throw new IllegalArgumentException("O nome não pode estar vazio");
        }
        adjacencias.computeIfAbsent(nome, ignorado -> new ArrayList<>());
    }

    public void conectar(String origem, String destino, int custo) {
        if (custo < 0) {
            throw new IllegalArgumentException("O custo não pode ser negativo");
        }
        adicionarVertice(origem);
        adicionarVertice(destino);
        boolean existe = adjacencias.get(origem).stream()
                .anyMatch(aresta -> aresta.destino().equals(destino));
        if (existe) {
            throw new IllegalArgumentException("Esta conexão já existe");
        }
        adjacencias.get(origem).add(new Aresta(destino, custo));
        if (!direcionado && !origem.equals(destino)) {
            adjacencias.get(destino).add(new Aresta(origem, custo));
        }
    }

    public boolean contemVertice(String nome) {
        return adjacencias.containsKey(nome);
    }

    public Set<String> vertices() {
        return new LinkedHashSet<>(adjacencias.keySet());
    }

    public List<Aresta> vizinhos(String vertice) {
        if (!contemVertice(vertice)) {
            throw new IllegalArgumentException("Vértice inexistente: " + vertice);
        }
        return List.copyOf(adjacencias.get(vertice));
    }
}
```

## Arquivo `Algoritmos.java`

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.Deque;
import java.util.HashMap;
import java.util.HashSet;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.PriorityQueue;
import java.util.Queue;
import java.util.Set;

public final class Algoritmos {
    private Algoritmos() {}

    public record Rota(List<String> caminho, long custo) {
        public Rota {
            caminho = List.copyOf(caminho);
        }
        public boolean encontrada() {
            return !caminho.isEmpty();
        }
    }

    public record Conexao(String origem, String destino, int custo) {}

    public record ResultadoRede(List<Conexao> conexoes,
                                long custoTotal,
                                boolean conectaTudo) {
        public ResultadoRede {
            conexoes = List.copyOf(conexoes);
        }
    }

    public record Ponto(double x, double y) {}
    private record Estado(String vertice, long custo) {}
    private record EstadoAEstrela(String vertice, long custo, double prioridade) {}

    public static List<String> bfs(Grafo grafo, String inicio) {
        validarVertice(grafo, inicio);
        Queue<String> fila = new ArrayDeque<>();
        Set<String> visitados = new HashSet<>();
        List<String> ordem = new ArrayList<>();
        fila.add(inicio);
        visitados.add(inicio);

        while (!fila.isEmpty()) {
            String atual = fila.remove();
            ordem.add(atual);
            for (Grafo.Aresta aresta : grafo.vizinhos(atual)) {
                if (visitados.add(aresta.destino())) {
                    fila.add(aresta.destino());
                }
            }
        }
        return ordem;
    }

    public static List<String> caminhoComMenosPassos(Grafo grafo,
                                                    String inicio,
                                                    String destino) {
        validarVertice(grafo, inicio);
        validarVertice(grafo, destino);
        Queue<String> fila = new ArrayDeque<>();
        Set<String> visitados = new HashSet<>();
        Map<String, String> anterior = new HashMap<>();
        fila.add(inicio);
        visitados.add(inicio);

        while (!fila.isEmpty()) {
            String atual = fila.remove();
            if (atual.equals(destino)) {
                return reconstruir(anterior, destino);
            }
            for (Grafo.Aresta aresta : grafo.vizinhos(atual)) {
                String proximo = aresta.destino();
                if (visitados.add(proximo)) {
                    anterior.put(proximo, atual);
                    fila.add(proximo);
                }
            }
        }
        return List.of();
    }

    public static List<String> dfs(Grafo grafo, String inicio) {
        validarVertice(grafo, inicio);
        Deque<String> pilha = new ArrayDeque<>();
        Set<String> visitados = new HashSet<>();
        List<String> ordem = new ArrayList<>();
        pilha.push(inicio);

        while (!pilha.isEmpty()) {
            String atual = pilha.pop();
            if (!visitados.add(atual)) {
                continue;
            }
            ordem.add(atual);
            List<Grafo.Aresta> vizinhos = grafo.vizinhos(atual);
            for (int i = vizinhos.size() - 1; i >= 0; i--) {
                String proximo = vizinhos.get(i).destino();
                if (!visitados.contains(proximo)) {
                    pilha.push(proximo);
                }
            }
        }
        return ordem;
    }

    public static Rota dijkstra(Grafo grafo, String inicio, String destino) {
        validarVertice(grafo, inicio);
        validarVertice(grafo, destino);
        Map<String, Long> distancias = new HashMap<>();
        Map<String, String> anterior = new HashMap<>();
        PriorityQueue<Estado> pendentes = new PriorityQueue<>(
                Comparator.comparingLong(Estado::custo));
        distancias.put(inicio, 0L);
        pendentes.add(new Estado(inicio, 0L));

        while (!pendentes.isEmpty()) {
            Estado estado = pendentes.remove();
            if (estado.custo() != distancias.getOrDefault(
                    estado.vertice(), Long.MAX_VALUE)) {
                continue; // Ignora uma entrada antiga na fila.
            }
            if (estado.vertice().equals(destino)) {
                return new Rota(reconstruir(anterior, destino), estado.custo());
            }
            for (Grafo.Aresta aresta : grafo.vizinhos(estado.vertice())) {
                if (estado.custo() > Long.MAX_VALUE - aresta.custo()) {
                    throw new ArithmeticException("Distância ultrapassa o limite de long");
                }
                long tentativa = estado.custo() + aresta.custo();
                if (tentativa < distancias.getOrDefault(
                        aresta.destino(), Long.MAX_VALUE)) {
                    distancias.put(aresta.destino(), tentativa);
                    anterior.put(aresta.destino(), estado.vertice());
                    pendentes.add(new Estado(aresta.destino(), tentativa));
                }
            }
        }
        return new Rota(List.of(), -1);
    }

    public static List<Set<String>> componentes(Grafo grafo) {
        exigirNaoDirecionado(grafo);
        Set<String> visitados = new HashSet<>();
        List<Set<String>> resultado = new ArrayList<>();
        for (String vertice : grafo.vertices()) {
            if (!visitados.add(vertice)) {
                continue;
            }
            Set<String> componente = new LinkedHashSet<>();
            Queue<String> fila = new ArrayDeque<>();
            fila.add(vertice);
            while (!fila.isEmpty()) {
                String atual = fila.remove();
                componente.add(atual);
                for (Grafo.Aresta aresta : grafo.vizinhos(atual)) {
                    if (visitados.add(aresta.destino())) {
                        fila.add(aresta.destino());
                    }
                }
            }
            resultado.add(componente);
        }
        return resultado;
    }

    public static List<String> ordenacaoTopologica(Grafo grafo) {
        if (!grafo.direcionado()) {
            throw new IllegalArgumentException("É necessário um grafo direcionado");
        }
        Map<String, Integer> grauEntrada = new LinkedHashMap<>();
        for (String vertice : grafo.vertices()) {
            grauEntrada.put(vertice, 0);
        }
        for (String origem : grafo.vertices()) {
            for (Grafo.Aresta aresta : grafo.vizinhos(origem)) {
                grauEntrada.merge(aresta.destino(), 1, Integer::sum);
            }
        }
        Queue<String> fila = new ArrayDeque<>();
        for (var entrada : grauEntrada.entrySet()) {
            if (entrada.getValue() == 0) {
                fila.add(entrada.getKey());
            }
        }
        List<String> ordem = new ArrayList<>();
        while (!fila.isEmpty()) {
            String atual = fila.remove();
            ordem.add(atual);
            for (Grafo.Aresta aresta : grafo.vizinhos(atual)) {
                String proximo = aresta.destino();
                int novoGrau = grauEntrada.merge(proximo, -1, Integer::sum);
                if (novoGrau == 0) {
                    fila.add(proximo);
                }
            }
        }
        if (ordem.size() != grafo.vertices().size()) {
            throw new IllegalStateException("Ciclo detectado nas dependências");
        }
        return ordem;
    }

    public static ResultadoRede kruskal(Grafo grafo) {
        exigirNaoDirecionado(grafo);
        List<Conexao> arestas = new ArrayList<>();
        for (String origem : grafo.vertices()) {
            for (Grafo.Aresta aresta : grafo.vizinhos(origem)) {
                if (origem.compareTo(aresta.destino()) < 0) {
                    arestas.add(new Conexao(origem, aresta.destino(), aresta.custo()));
                }
            }
        }
        arestas.sort(Comparator.comparingInt(Conexao::custo));
        UniaoBusca grupos = new UniaoBusca(grafo.vertices());
        List<Conexao> escolhidas = new ArrayList<>();
        long total = 0;
        for (Conexao aresta : arestas) {
            if (grupos.unir(aresta.origem(), aresta.destino())) {
                escolhidas.add(aresta);
                total += aresta.custo();
            }
        }
        boolean conectaTudo = grafo.vertices().isEmpty()
                || escolhidas.size() == grafo.vertices().size() - 1;
        return new ResultadoRede(escolhidas, total, conectaTudo);
    }

    public static Rota aEstrela(Grafo grafo,
                              Map<String, Ponto> coordenadas,
                              String inicio,
                              String destino) {
        validarVertice(grafo, inicio);
        validarVertice(grafo, destino);
        // Contrato: custo de cada trecho >= distância euclidiana entre as pontas.
        for (String vertice : grafo.vertices()) {
            if (!coordenadas.containsKey(vertice)) {
                throw new IllegalArgumentException("Coordenada ausente: " + vertice);
            }
            for (Grafo.Aresta aresta : grafo.vizinhos(vertice)) {
                double reta = distancia(coordenadas.get(vertice),
                        coordenadas.get(aresta.destino()));
                if (aresta.custo() + 1e-9 < reta) {
                    throw new IllegalArgumentException(
                            "Custo menor que a distância em linha reta: " + vertice);
                }
            }
        }
        Map<String, Long> melhorCusto = new HashMap<>();
        Map<String, String> anterior = new HashMap<>();
        PriorityQueue<EstadoAEstrela> pendentes = new PriorityQueue<>(
                Comparator.comparingDouble(EstadoAEstrela::prioridade));
        melhorCusto.put(inicio, 0L);
        pendentes.add(new EstadoAEstrela(inicio, 0,
                distancia(coordenadas.get(inicio), coordenadas.get(destino))));

        while (!pendentes.isEmpty()) {
            EstadoAEstrela estado = pendentes.remove();
            if (estado.custo() != melhorCusto.getOrDefault(
                    estado.vertice(), Long.MAX_VALUE)) {
                continue;
            }
            if (estado.vertice().equals(destino)) {
                return new Rota(reconstruir(anterior, destino), estado.custo());
            }
            for (Grafo.Aresta aresta : grafo.vizinhos(estado.vertice())) {
                if (estado.custo() > Long.MAX_VALUE - aresta.custo()) {
                    throw new ArithmeticException("Distância ultrapassa o limite de long");
                }
                long novoCusto = estado.custo() + aresta.custo();
                if (novoCusto < melhorCusto.getOrDefault(
                        aresta.destino(), Long.MAX_VALUE)) {
                    melhorCusto.put(aresta.destino(), novoCusto);
                    anterior.put(aresta.destino(), estado.vertice());
                    double h = distancia(coordenadas.get(aresta.destino()),
                            coordenadas.get(destino));
                    pendentes.add(new EstadoAEstrela(aresta.destino(),
                            novoCusto, novoCusto + h));
                }
            }
        }
        return new Rota(List.of(), -1);
    }

    private static double distancia(Ponto a, Ponto b) {
        return Math.hypot(a.x() - b.x(), a.y() - b.y());
    }

    private static List<String> reconstruir(Map<String, String> anterior,
                                            String destino) {
        Deque<String> caminho = new ArrayDeque<>();
        for (String atual = destino; atual != null; atual = anterior.get(atual)) {
            caminho.addFirst(atual);
        }
        return List.copyOf(caminho);
    }

    private static void validarVertice(Grafo grafo, String vertice) {
        if (!grafo.contemVertice(vertice)) {
            throw new IllegalArgumentException("Vértice inexistente: " + vertice);
        }
    }

    private static void exigirNaoDirecionado(Grafo grafo) {
        if (grafo.direcionado()) {
            throw new IllegalArgumentException("É necessário um grafo não direcionado");
        }
    }

    private static final class UniaoBusca {
        private final Map<String, String> pai = new HashMap<>();
        private final Map<String, Integer> altura = new HashMap<>();

        private UniaoBusca(Set<String> vertices) {
            for (String vertice : vertices) {
                pai.put(vertice, vertice);
                altura.put(vertice, 0);
            }
        }

        private String encontrar(String x) {
            if (!pai.get(x).equals(x)) {
                pai.put(x, encontrar(pai.get(x)));
            }
            return pai.get(x);
        }

        private boolean unir(String a, String b) {
            String raizA = encontrar(a);
            String raizB = encontrar(b);
            if (raizA.equals(raizB)) {
                return false;
            }
            int alturaA = altura.get(raizA);
            int alturaB = altura.get(raizB);
            if (alturaA < alturaB) {
                pai.put(raizA, raizB);
            } else if (alturaA > alturaB) {
                pai.put(raizB, raizA);
            } else {
                pai.put(raizB, raizA);
                altura.put(raizA, alturaA + 1);
            }
            return true;
        }
    }
}
```
