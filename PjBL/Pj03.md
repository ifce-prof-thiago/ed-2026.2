## Missão 1 — Como organizar uma cidade? (100 XP)

### O problema

Uma cidade inteligente precisa organizar seus serviços:

```text
Central
├── Saúde
│   ├── Hospital
│   └── Posto
└── Transporte
    ├── Ônibus
    └── Metrô
```

**Antes de ler a explicação, responda no papel:**

1. Qual elemento está no topo da organização?
2. Quais elementos estão diretamente ligados a `Saúde`?
3. Quem está acima de `Hospital`?
4. Quais elementos não possuem outros elementos abaixo deles?
5. Quantas ligações são necessárias para ir de `Central` até `Metrô`?
6. Seria possível colocar `Central` como subordinada de `Hospital` sem criar uma organização circular?

### O que você descobriu

Essa organização é uma **árvore**. Seus elementos são chamados de **nós**.

| Palavra | O que significa | Exemplo |
|---|---|---|
| Raiz | Nó de onde a árvore começa | `Central` |
| Pai | Nó imediatamente acima de outro | `Saúde` é pai de `Hospital` |
| Filho | Nó imediatamente abaixo de outro | `Hospital` é filho de `Saúde` |
| Folha | Nó sem filhos | `Posto` |
| Nível ou profundidade | Quantidade de ligações desde a raiz | `Metrô` tem profundidade 2 |
| Altura de um nó | Maior número de ligações até uma folha abaixo dele | `Central` tem altura 2 |

**Regras importantes:** a raiz não tem pai; todo outro nó tem **exatamente um pai**; não existem ciclos; e, a partir da raiz, é possível chegar a todos os nós.

**Desafio:** acrescente `Educação` como filha de `Central` e `Escola` e `Biblioteca` como filhas de `Educação`. Agora determine quantos nós, folhas e níveis existem.

**Dica:** conte os próprios nomes para descobrir os nós; para as folhas, procure quem não tem filhos. Aqui, a raiz está no nível 0.

**Antes de avançar:** por que uma árvore representa bem departamentos de uma organização, mas não necessariamente todas as ruas de uma cidade?

## Missão 2 — Transforme o desenho em código (100 XP)

### O problema

Queremos representar `Central`, `Saúde`, `Hospital` e os demais elementos em Java. Você já conhece `List`. Como guardar um elemento e seus filhos?

**Pense primeiro:**

- Uma `List<String>` guarda os nomes, mas consegue indicar **quem é filho de quem**?
- E se cada elemento guardasse **seu próprio nome e uma lista de outros elementos**?
- Um filho poderia guardar outra lista de filhos?

### Passo 1 — Crie `ArvoreCidade.java`

```java
import java.util.*;

public class ArvoreCidade {
    static class No {
        final String nome;
        final List<No> filhos = new ArrayList<>();

        No(String nome) {
            this.nome = nome;
        }

        No adicionar(String nome) {
            No novo = new No(nome);
            filhos.add(novo);
            return novo;
        }
    }

    static No montar() {
        No central = new No("Central");

        No saude = central.adicionar("Saúde");
        saude.adicionar("Hospital");
        saude.adicionar("Posto");

        No transporte = central.adicionar("Transporte");
        transporte.adicionar("Ônibus");
        transporte.adicionar("Metrô");

        return central;
    }

    public static void main(String[] args) {
        No raiz = montar();
        System.out.println(raiz.nome);
        System.out.println(raiz.filhos.size());
    }
}
```

Execute:

```bash
javac -encoding UTF-8 ArvoreCidade.java
java ArvoreCidade
```

Saída esperada:

```text
Central
2
```

### Entenda o que aconteceu

- `No` representa **um elemento**.
- `List<No>` representa seus **filhos**.
- O método `adicionar` cria um filho e devolve esse filho para que você possa acrescentar os descendentes dele.
- `montar()` devolve a raiz de toda a organização.

**Desafio:** modifique `montar()` para acrescentar `Educação`, `Escola` e `Biblioteca`, como na missão anterior.

**Teste:** `raiz.filhos.size()` deve passar de `2` para `3`.

**Pergunta:** por que `List<No>` permite formar vários níveis, sem precisar criar uma classe para cada nível?

> A partir de agora, acrescente os novos métodos **dentro de `ArvoreCidade`**, mas **fora do método `main`**. Para os primeiros testes, mantenha a árvore original, com sete nós.

## Missão 3 — Visite todos os setores usando uma fila (100 XP)

### O problema

Um coordenador quer consultar os setores **nível por nível**: primeiro a Central, depois seus setores e, por último, os serviços de cada setor.

**Sem programar:** escreva a ordem em que os sete nós devem aparecer.

**Pergunta decisiva:** entre lista, pilha e fila, qual estrutura atende primeiro os elementos que chegaram primeiro?

### A estratégia

1. Coloque a raiz na **fila**.
2. Retire o primeiro nó.
3. Visite esse nó.
4. Coloque seus filhos no fim da fila.
5. Repita até não haver ninguém na fila.

Isso se chama **percurso em largura**, ou **percurso por níveis**.

### Programe

Adicione o método à classe `ArvoreCidade`:

```java
static List<String> porNivel(No raiz) {
    List<String> ordem = new ArrayList<>();
    Queue<No> fila = new ArrayDeque<>();

    fila.add(raiz);

    while (!fila.isEmpty()) {
        No atual = fila.remove();
        ordem.add(atual.nome);

        for (No filho : atual.filhos) {
            fila.add(filho);
        }
    }

    return ordem;
}
```

No `main`, teste:

```java
System.out.println(porNivel(raiz));
```

Resultado esperado para a árvore original:

```text
[Central, Saúde, Transporte, Hospital, Posto, Ônibus, Metrô]
```

**Investigue:** acompanhe a fila após visitar `Central` e depois após visitar `Saúde`. Quais elementos estão esperando em cada momento?

**Desafio:** crie `existe(No raiz, String nome)`, que devolva `true` quando encontrar um setor e `false` quando ele não existir.

**Dicas graduais:**

1. Reaproveite a fila do método `porNivel`.
2. Compare `atual.nome.equals(nome)` após retirar cada nó.
3. Se encontrar, retorne `true` imediatamente. Se a fila acabar, retorne `false`.

**Testes:** `existe(raiz, "Hospital")` deve ser `true`; `existe(raiz, "Aeroporto")` deve ser `false`.

## Missão 4 — Explore um setor por inteiro usando uma pilha (100 XP)

### O problema

Outra equipe precisa concluir **todos os serviços de Saúde antes de começar Transporte**. Percorrer por níveis não atende a essa necessidade.

**Pergunta:** como visitar um setor, depois um de seus filhos, e continuar descendo antes de voltar aos irmãos?

Você já conhece uma estrutura em que o **último a entrar é o primeiro a sair**: a **pilha**.

### Programe

```java
static List<String> emProfundidade(No raiz) {
    List<String> ordem = new ArrayList<>();
    Deque<No> pilha = new ArrayDeque<>();

    pilha.push(raiz);

    while (!pilha.isEmpty()) {
        No atual = pilha.pop();
        ordem.add(atual.nome);

        // Empilhamos de trás para frente para visitar
        // os filhos na ordem em que foram cadastrados.
        for (int i = atual.filhos.size() - 1; i >= 0; i--) {
            pilha.push(atual.filhos.get(i));
        }
    }

    return ordem;
}
```

No `main`:

```java
System.out.println(emProfundidade(raiz));
```

Resultado esperado:

```text
[Central, Saúde, Hospital, Posto, Transporte, Ônibus, Metrô]
```

Isso é um **percurso em profundidade**. Como visitamos cada nó **antes** dos seus filhos, essa ordem é chamada de **pré-ordem**.

**Desafio:** troque o laço `for` por um laço que empilhe os filhos do primeiro ao último. Preveja como a saída mudará e depois execute.

**Pergunta:** qual percurso escolheria para ver setores por nível? E qual escolheria para terminar um departamento inteiro antes do próximo?

## Missão 5 — Descubra a recursão e analise a árvore (100 XP)

### O problema

A prefeitura precisa saber:

- Quantos nós existem na organização?
- Quantos nós são **folhas**?
- Qual é a **altura** da organização?

Até agora, usamos fila e pilha. Mas há outra possibilidade: **pedir que cada filho resolva uma parte menor do problema**.

### Passo 1 — Conte os nós

Imagine o seguinte raciocínio:

> A quantidade de nós de um setor é **1 (o próprio setor) + a quantidade de nós de todos os seus filhos**.

Esse raciocínio pode ser escrito assim:

```java
static int contarNos(No no) {
    int total = 1;

    for (No filho : no.filhos) {
        total += contarNos(filho);
    }

    return total;
}
```

Esse método chama **ele mesmo** para resolver problemas menores. Isso é **recursão**.

A recursão termina porque, ao alcançar uma folha, `no.filhos` está vazio: o `for` não executa e o método devolve `1`.

Teste em `main`:

```java
System.out.println(contarNos(raiz)); // 7
```

### Passo 2 — Sua vez: conte as folhas

Crie este método e preencha as partes indicadas:

```java
static int contarFolhas(No no) {
    // TODO: se no.filhos estiver vazio, retorne 1.

    int total = 0;
    for (No filho : no.filhos) {
        // TODO: some as folhas de cada filho.
    }
    return total;
}
```

**Dicas:**

1. Use `no.filhos.isEmpty()` para identificar uma folha.
2. A contagem de folhas **não** inclui o próprio nó quando ele tem filhos.
3. A chamada recursiva tem a forma `contarFolhas(filho)`.

**Resultado esperado:** `4`.

### Passo 3 — Desafio: calcule a altura

Neste tutorial, medimos a altura em **ligações**. Assim, uma folha tem altura `0`.

**Raciocínio:**

- Se um nó não possui filhos, sua altura é `0`.
- Se possui filhos, sua altura é `1 + a maior altura entre seus filhos`.

Implemente `static int altura(No no)` usando `Math.max` e recursão.

**Resultado esperado:** `2`.

**Perguntas finais:** qual é a condição que faz cada chamada recursiva parar? O que aconteceria se os nós formassem um ciclo?

## Missão 6 — Encontre códigos sem examinar tudo (100 XP)

### O problema

Agora a cidade precisa organizar números de chamados. Uma lista pode armazená-los, mas como encontrá-los sem verificar cada elemento?

Considere estes números, inseridos nesta ordem:

```text
40, 20, 60, 10, 30, 50, 70
```

Desenhe uma estrutura seguindo duas regras:

1. Cada nó tem **no máximo dois filhos**: esquerda e direita.
2. Números **menores** ficam na subárvore da esquerda; números **maiores**, na da direita.

O desenho correto fica assim:

```text
        40
       /  \
     20    60
    /  \  /  \
   10  30 50  70
```

Essa estrutura é uma **árvore binária de busca (ABB)**. Observe que agora cada nó precisa de apenas duas referências: `esquerda` e `direita`.

**Antes de programar:**

1. Para procurar `30`, qual comparação você faz primeiro?
2. Depois de encontrar `20`, para qual lado deve seguir?
3. Se procurar `99`, em que momento saberá que o número não existe?

### Passo 1 — Crie `ArvoreBusca.java`

```java
public class ArvoreBusca {
    static class No {
        final int valor;
        No esquerda;
        No direita;

        No(int valor) {
            this.valor = valor;

        if (no == null) return new No(valor);

        if (valor < no.valor) {
            no.esquerda = inserir(no.esquerda, valor);
        } else if (valor > no.valor) {
            no.direita = inserir(no.direita, valor);
        }

        // Nesta versão, valores iguais não são inseridos.
        return no;

        return false;
    }

    public static void main(String[] args) {
        No raiz = null;
        int[] numeros = {40, 20, 60, 10, 30, 50, 70};

        for (int numero : numeros) {
            raiz = inserir(raiz, numero);
        }

        System.out.println(contem(raiz, 30));
        System.out.println(contem(raiz, 99));

```

> No início, o método `contem` sempre devolve `false`: isso é **intencional**. Sua tarefa é completá-lo.

### Passo 2 — Implemente a busca

Use estas decisões, nesta ordem:

1. Se o nó recebido é `null`, o número não foi encontrado.
2. Se `no.valor == valor`, encontramos o número.
3. Se `valor < no.valor`, procure na esquerda.
4. Caso contrário, procure na direita.

**Dica:** chamadas como `contem(no.esquerda, valor)` resolvem a busca em uma parte menor da árvore.

**Testes esperados:**

```text
true
false
```

## Missão 7 — Mostre os códigos em ordem e descubra uma limitação (100 XP)

### O problema

O gestor quer imprimir todos os números em **ordem crescente**, sem copiá-los para uma lista e usar `sort`.

**Investigue o desenho da missão anterior:**

- Onde estão os menores números?
- Onde está o número intermediário de cada parte da árvore?
- Onde estão os maiores?

A ordem que resolve o problema é: **esquerda → nó atual → direita**. Ela é chamada de **percurso em ordem**.

### Programe

Acrescente a `ArvoreBusca`:

```java
static void emOrdem(No no) {
    if (no == null) return;

    emOrdem(no.esquerda);
    System.out.print(no.valor + " ");
    emOrdem(no.direita);
}
```

Chame ao final do `main`:

```java
emOrdem(raiz);
System.out.println();
```

Resultado esperado, antes de inserir `25` e `65`:

```text
10 20 30 40 50 60 70
```

### Um problema inesperado

Crie outra árvore e insira, nesta ordem:

```text
10, 20, 30, 40, 50
```

**Desenhe o resultado.** Ela fica parecida com uma lista inclinada para a direita. A busca pode precisar percorrer quase todos os nós.

**O que você aprendeu:** a busca em uma ABB depende da **altura** da árvore.

- Em uma árvore bem distribuída, a busca tende a ser eficiente: **O(log n)**.
- Em uma árvore muito inclinada, pode chegar a **O(n)**.

> Uma ABB simples não se equilibra automaticamente. Mais adiante, você poderá estudar árvores AVL e rubro-negras para resolver esse problema.

**Desafio para concluir a missão:** explique, usando os dois desenhos, por que a mesma regra de inserção pode produzir árvores com alturas diferentes.

## Resumo para consultar enquanto programa

| Necessidade | Técnica | Estrutura usada |
|---|---|---|
| Organizar informações hierárquicas | Árvore geral | Nó + `List<No>` |
| Percorrer nível por nível | Busca em largura | `Queue` / `ArrayDeque` |
| Explorar um ramo antes dos outros | Busca em profundidade | `Deque` como pilha |
| Contar nós ou calcular altura | Recursão | Chamadas de métodos |
| Pesquisar valores ordenados | Árvore binária de busca | Nó com `esquerda` e `direita` |
| Imprimir ABB em ordem crescente | Percurso em ordem | Recursão |

**Ponte para o próximo assunto:** uma árvore também pode ser vista como um tipo especial de **grafo conectado e sem ciclos**. Ao estudar grafos, você encontrará estruturas em que os nós podem ter diferentes ligações e múltiplos caminhos entre eles.

### Missão 3 — Buscar um nome

```java
static boolean existe(No raiz, String nome) {
    Queue<No> fila = new ArrayDeque<>();
    fila.add(raiz);

    while (!fila.isEmpty()) {
        No atual = fila.remove();
        if (atual.nome.equals(nome)) return true;
        fila.addAll(atual.filhos);
    }
    return false;
}
```

### Missão 5 — Contar folhas e calcular altura

Adicione dentro de `ArvoreCidade`:

```java
static int contarFolhas(No no) {
    if (no.filhos.isEmpty()) return 1;

    int total = 0;
    for (No filho : no.filhos) {
        total += contarFolhas(filho);
    }
    return total;
}

static int altura(No no) {
    int maior = 0;
    for (No filho : no.filhos) {
        maior = Math.max(maior, 1 + altura(filho));
    }
    return maior;
}
```

### Missão 6 — Pesquisar na ABB

Substitua o método `contem` de `ArvoreBusca` por:

```java
static boolean contem(No no, int valor) {
    if (no == null) return false;
    if (no.valor == valor) return true;

    if (valor < no.valor) {
        return contem(no.esquerda, valor);
    }
    return contem(no.direita, valor);
}
```

### Missão 7 — Por que a altura importa?

Inserindo `40, 20, 60, 10, 30, 50, 70`, a árvore tem altura **2**. Inserindo `10, 20, 30, 40, 50`, todos os nós ficam à direita do anterior e a altura fica **4**. Por isso, nem toda ABB oferece a mesma eficiência de busca.
