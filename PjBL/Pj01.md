## 1. O Grande Desafio

Você está na equipe de um **editor de texto colaborativo** e precisa implementar o histórico de **"Desfazer/Refazer" (Ctrl+Z / Ctrl+Y)**.

A ideia óbvia seria usar um Array:

```java
String[] historico = new String[100]; // por que 100? e se precisar de mais?
```

Isso gera dois problemas reais:

- **Tamanho fixo:** se o histórico crescer além do previsto, o array precisa ser recriado e todo o conteúdo copiado.
- **Inserção/remoção custosa:** remover uma ação do meio do histórico exige deslocar todos os elementos seguintes — custo O(n).

Precisamos de uma estrutura que cresça sob demanda e permita inserir/remover no início em tempo constante — **O(1)**. É isso que a **Lista Encadeada** resolve.

---

## 2. Anatomia de uma Lista Encadeada

Pense em um **trem**: cada **vagão** carrega uma **carga** (o dado) e um **gancho** para o **próximo vagão**. Você só precisa saber qual é o primeiro vagão; a partir dele, segue os ganchos até não haver mais vagão conectado.

| Conceito | O que é | Analogia |
|---|---|---|
| **Nó (Node)** | Unidade básica da lista | O vagão |
| **Dado (Data)** | Informação armazenada no nó | A carga do vagão |
| **Próximo (Next)** | Referência ao próximo nó (ou `null` se for o último) | O gancho entre vagões |

```
[ HEAD ] -> [ Dado: "Música A" | Next ] -> [ Dado: "Música B" | Next ] -> [ Dado: "Música C" | Next: null ]
```

A lista guarda apenas a referência ao primeiro nó (`head`). Inserir no início é O(1): basta criar o nó novo apontando para o antigo `head` e atualizar o `head`. Não há deslocamento de elementos, como haveria em um array.

```java
public class ListaEncadeada {

    private static class No {
        String dado;
        No proximo;

        No(String dado) {
            this.dado = dado;
            this.proximo = null;
        }
    }

    private No head;
    private int tamanho;

    public ListaEncadeada() {
        this.head = null;
        this.tamanho = 0;
    }

    public void inserirNoInicio(String dado) {
        No novoNo = new No(dado);
        novoNo.proximo = this.head;
        this.head = novoNo;
        this.tamanho++;
    }

    public void inserirNoFim(String dado) {
        No novoNo = new No(dado);

        if (this.head == null) {
            this.head = novoNo;
            this.tamanho++;
            return;
        }

        No atual = this.head;
        while (atual.proximo != null) {
            atual = atual.proximo;
        }
        atual.proximo = novoNo;
        this.tamanho++;
    }

    public void exibirLista() {
        No atual = this.head;
        while (atual != null) {
            System.out.print(atual.dado + " -> ");
            atual = atual.proximo;
        }
        System.out.println("null");
    }

    public int getTamanho() {
        return this.tamanho;
    }

    public boolean buscar(String dado) {
        No atual = this.head;
        while (atual != null) {
            if (atual.dado.equals(dado)) {
                return true;
            }
            atual = atual.proximo;
        }
        return false;
    }

    public void deletar(String dado) {
        if (this.head == null) {
            return;
        }

        // Caso especial: o nó a remover é o head
        if (this.head.dado.equals(dado)) {
            this.head = this.head.proximo;
            this.tamanho--;
            return;
        }

        No anterior = this.head;
        No atual = this.head.proximo;

        while (atual != null) {
            if (atual.dado.equals(dado)) {
                anterior.proximo = atual.proximo;
                this.tamanho--;
                return;
            }
            anterior = atual;
            atual = atual.proximo;
        }
        // Se chegou aqui, o dado não existia na lista — nada a fazer
    }

    public static void main(String[] args) {
        ListaEncadeada historico = new ListaEncadeada();

        historico.inserirNoFim("Digitou 'Olá'");
        historico.inserirNoFim("Digitou 'Olá, mundo'");
        historico.inserirNoInicio("Abriu o documento");

        System.out.println("Tamanho: " + historico.getTamanho());
        historico.exibirLista();

        System.out.println(historico.buscar("Digitou 'Olá'"));
        historico.deletar("Digitou 'Olá'");
        historico.exibirLista();
    }
}
```

<summary>Clique para revelar as respostas das perguntas de reflexão</summary>

1. **Acesso ao 50º elemento:** em um Array, o índice indica diretamente o endereço de memória do elemento, então o acesso é O(1). Em uma Lista Encadeada não existe índice — o único ponto de entrada é o `head`. Para chegar ao 50º nó é preciso percorrer, um a um, os 49 nós anteriores seguindo o `proximo`, o que custa O(n).

2. **Inserção no início:** em um Array, inserir no início exige deslocar todos os elementos existentes uma posição à frente para abrir espaço (O(n)). Em uma Lista Encadeada basta criar o novo nó e apontar seu `proximo` para o antigo `head`, sem tocar em nenhum outro elemento — por isso é O(1).

3. **Quando preferir Array/ArrayList:** quando o acesso aleatório por índice é frequente (ex: `lista.get(i)`), quando o tamanho é conhecido e estável, ou quando a economia de memória importa — cada nó da lista encadeada gasta memória extra com a referência `proximo`, além de a travessia sequencial ser mais lenta para buscas por posição do que o acesso direto de um array.
