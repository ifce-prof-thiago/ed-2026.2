# 🔗 Pj02: Sistema de Fila de Atendimento com Lista Encadeada

**Curso:** ADS — Estrutura de Dados  
**Metodologia:** PBL / PjBL  
**Linguagem:** Java  
**Tema:** Listas encadeadas e resolução de problema real

> Este trabalho tem como objetivo aplicar os conceitos de lista encadeada para resolver um problema prático de gestão de fila. Vocês devem usar a estrutura `LinkedList` como base e criar uma solução funcional em Java.

---

## 1. Contexto do problema

Uma universidade está implantando um sistema para controlar a fila de atendimento de alunos em vários balcões:

- Matrícula
- Financeiro
- Biblioteca
- Laboratório
- Atendimento pedagógico

Cada aluno precisa ser registrado na fila e atendido em ordem conforme regras definidas. A estrutura de dados ideal para esse cenário é a lista encadeada, porque ela permite:

- inserir no início ou no fim sem rearranjar todo o conteúdo;
- remover o primeiro ou último elemento com eficiência;
- percorrer a lista para localizar, remover ou listar os dados.

---

## 2. Desafio

Crie um sistema em Java para gerenciar a fila de atendimento de alunos. A fila deve permitir:

1. adicionar um aluno no fim da fila;
2. adicionar um aluno no início da fila;
3. atender o próximo aluno da fila;
4. remover um aluno específico;
5. verificar se um aluno existe na fila;
6. listar todos os alunos em ordem;
7. contar quantos alunos estão na fila;
8. remover o último aluno da fila;

A solução deve ser baseada na estrutura `LinkedList` e deve funcionar corretamente em casos especiais, como:

- fila vazia;
- um único elemento;
- busca por nome inexistente;
- remoção do primeiro termo;
- remoção do último termo.

---

## 3. Requisitos funcionais

### 3.1 Classe `Aluno`
Crie uma classe `Aluno` com os seguintes atributos:

- `nome` (String)
- `matricula` (String)
- `prioridade` (int)

E também deve conter:

- construtor;
- getters e setters;
- `toString()` para exibir os dados do aluno.

### 3.2 Classe `LinkedList`
Você deve continuar usando a estrutura de lista encadeada já desenvolvida em aula, corrigindo e ampliando as operações:

- `insertFirst(String data)`
- `insertEnd(String data)`
- `removeFirst()`
- `removeEnd()`
- `contains(String data)`
- `get(String data)`
- `print()`

Além disso, a classe deve ganhar operações mais úteis para o problema:

- `size()`
- `isEmpty()`
- `remove(String data)`
- `search(String data)`
- `insertAt(int index, String data)`

### 3.3 Classe `FilaAtendimento`
Crie uma classe que orquestra os alunos na fila:

- `adicionarAlunoNoFim(Aluno aluno)`
- `adicionarAlunoNoInicio(Aluno aluno)`
- `atenderProximo()`
- `removerAluno(String matricula)`
- `buscarAluno(String matricula)`
- `listarAlunos()`
- `quantidadeAlunos()`

## 5. Exemplo de cenário

Exemplo de uso:

```java
public class Main {
    public static void main(String[] args) {
        FilaAtendimento fila = new FilaAtendimento();

        fila.adicionarAlunoNoFim(new Aluno("Ana", "202401", 2));
        fila.adicionarAlunoNoFim(new Aluno("Bruno", "202402", 1));
        fila.adicionarAlunoNoInicio(new Aluno("Carla", "202403", 3));

        fila.listarAlunos();
        System.out.println("Quantidade: " + fila.quantidadeAlunos());

        fila.atenderProximo();
        fila.removerAluno("202402");
        fila.listarAlunos();
    }
}
```

Saída esperada (modelo simples):

```text
Carla - 202403 - prioridade 3
Ana - 202401 - prioridade 2
Bruno - 202402 - prioridade 1
Quantidade: 3
Carla - 202403 - prioridade 3
Ana - 202401 - prioridade 2
```

## 9. Dica de modelagem

Você pode criar a fila em duas formas:

- usando diretamente a `LinkedList` para armazenar os nomes ou matrículas;
- criando uma camada extra `FilaAtendimento`, que usa a lista encadeada internamente para gerenciar os objetos `Aluno`.

A segunda opção é recomendada, porque separa melhor as responsabilidades e deixa o código mais organizado.
